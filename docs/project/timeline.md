TIMELINE PROJECT
DIGITAL IMAGE PROCESSING
DOSEN: ANDI BASO KASWAR, S.PD., M.KOM.

A. Tujuan:

1. Project MK ditujukan untuk melatih kemampuan mahasiswa untuk menganalisis permasalahan dan menentukan solusi permasalahan dengan menerapkan teknik-teknik dalam penngolahan citra digital
2. Project MK bertujuan untuk membangun ketekunan, daya juang, kemampuan berkomunikasi, serta manajemen waktu mahasiswa
3. Paper sebagai bentuk ilmiah dari laporan project (pengganti laporan), output nyata hasil pembelajaran MK Digital Image Processing
4. Paper bertujuan untuk membiasakan mahasiswa berpikir secara ilmiah dan melatih mahasiswa menuangkan ide gagasannya kedalam karya tulis ilmiah yang menjadi salah satu tujuan pendidikan.
5. Paper bertujuan untuk membangun integritas dan kejujuran mahasiswa, percaya diri dan bangga dengan karyanya sendiri.
6. Publikasi paper bertujuan untuk mendokumentasikan karya mahasiswa secara ilmiah sehingga bisa dimanfaatkan di kemudian hari serta bermanfaat untuk orang lain.
